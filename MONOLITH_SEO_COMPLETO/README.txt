MONOLITH - paquete SEO para Vercel

ARCHIVOS:
- index.html      -> reemplaza tu archivo actual
- robots.txt      -> permite rastreo y apunta al sitemap
- sitemap.xml     -> sitemap de la página principal
- favicon.png     -> favicon de MONOLITH
- og-image.png    -> imagen para compartir en redes
- site.webmanifest-> información básica para navegadores
- README.txt      -> instrucciones

IMPORTANTE:
1. Sube TODOS estos archivos a la raíz de tu repositorio de GitHub.
2. Vercel volverá a desplegar automáticamente.
3. Abre:
   https://monolith-client-nine.vercel.app/
   https://monolith-client-nine.vercel.app/robots.txt
   https://monolith-client-nine.vercel.app/sitemap.xml
4. En Google Search Console agrega:
   https://monolith-client-nine.vercel.app/
5. Cuando Google te entregue el meta tag de verificación, reemplaza el comentario
   de google-site-verification en index.html por el código real.
6. Después solicita indexación de la URL principal y envía sitemap.xml.

NOTA:
El SEO puede mejorar la capacidad de Google para entender y posicionar el sitio,
pero ninguna modificación garantiza primeras posiciones. El posicionamiento depende
también de competencia, contenido, enlaces, experiencia del usuario y tiempo.
